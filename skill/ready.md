# 最終回答へ進む

## tools

- ready_to_answer
    - 今回の tool_calls の結果を待ったあと、追加のツールは不要で最終回答に進むと宣言する
    - 副作用なし
    - 引数なし

## スキルの手順

他のスキルの実ツールと**同じターンで** `ready_to_answer` を呼ぶ。

呼ぶとき
- エアコンON、照明OFF、ToDo追加、アラームセットなど、結果を見ずに答えられる操作を呼び終えた
- 温度取得や一覧取得だけで足りて、その結果をユーザーに返す

呼ぶな
- 温度を見てからモードを決めて操作する、一覧を見てからファイルを読む、など次のツールが結果待ち
- 実ツールをまだ呼んでいない

実ツールなしで `ready_to_answer` だけ呼ぶな。
