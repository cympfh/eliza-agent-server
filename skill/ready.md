# 最終回答へ進む

## tools

- ready_to_answer
    - このターンの実ツールの結果を待ったあと、追加のツールは不要で最終回答に進むと宣言する
    - 副作用なし
    - 引数なし

## スキルの手順

実ツールと `ready_to_answer` は同じ応答の tool_calls に並べる。実行済みかどうかは見ない。

呼ぶとき
- このターンで出す実ツール（エアコンON、照明OFF、ToDo追加、温度取得だけ、など）のあと、次のツールが要らない

呼ぶな
- このターンの結果を見てから次のツールを決める（室温取得のあと操作、一覧のあとファイル読み）
- このターンに実ツールを出さず `ready_to_answer` だけ出す
